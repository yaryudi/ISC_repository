# ISC (InSpired Care For Connection)  
노인과 복지사를 연결하는 매칭 웹서비스  

---

## 📖 소개  
**ISC (InSpired Care For Connection)** 는 노인과 복지사를 연결해주는 플랫폼입니다.  
회원가입, 로그인, 매칭, 채팅 기능을 통해 양측이 손쉽게 연결되고 소통할 수 있도록 설계되었습니다.  

---

## 🚀 주요 기능  
- 🔐 **회원가입 / 로그인** : 사용자 계정 생성 및 인증  
- 📝 **정보 입력** : 노인/복지사 프로필 관리  
- 💬 **실시간 채팅** : 매칭된 사용자 간 대화 기능  
- 🤝 **매칭 기능** : 조건 기반 매칭 알고리즘  
- 🏠 **홈화면** : 서비스 시작 페이지
-  **TODO** : 해야할 일을 캘린더로 정리

## 🛠 기술 스택  
- **Backend** : Flask (Python)  
- **Database** : MongoDB  
- **Frontend** : HTML, CSS, JavaScript  
- **기타** : RESTful API, Socket 기반 채팅
