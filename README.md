## 📖 소개  
**ISC (InSpired Care For Connection)** 는 노인과 복지사를 연결해주는 플랫폼입니다.  
회원가입, 로그인, 매칭, 채팅 기능을 통해 양측이 손쉽게 연결되고 소통할 수 있도록 설계되었습니다.  

---

## 🚀 주요 기능  
- 🔐 **회원가입 / 로그인** : 사용자 계정 생성 및 인증  
- 📝 **정보 입력** : 노인/복지사 프로필 관리  
- 💬 **실시간 채팅** : 매칭된 사용자 간 대화 기능  
- 🤝 **매칭 기능** : 조건 기반 매칭 알고리즘  
- 🏠 **홈화면** : 서비스 시작 페이지
-  **TODO** : 해야할 일을 캘린더로 정리

---

## 🛠 기술 스택  
- **Backend** : Flask (Python)  
- **Database** : MongoDB  
- **Frontend** : HTML, CSS, JavaScript  
- **기타** : RESTful API, Socket 기반 채팅

## 유의 사항
mongo db의 URL을 그대로 사용할 수 없게 DB 계정의 비번과 아이디를 변경함.(코드는 유지하나 DB에 접근이 되지 않을 것) 
사유는 해당 서버의 보안문제로 URL에 데이터 접근 비밀번호와 아이디가 기록되어있음.
데이터베이스 접근용 URL이 필요한 경우, 혹은 문제 발생 시 rjh0162@uos.ac.kr로 연락바람.
또한, 해당 URL사용 후, 리포리지에 해당 URL을 남기지 않아야함.
